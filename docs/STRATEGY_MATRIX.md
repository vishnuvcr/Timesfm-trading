# Strategy research matrix

Scalping: short-horizon return/range forecast plus uncertainty and execution filters.

Intraday: trend, reversion, breakout, ORB and VWAP timing.

BTST: overnight gap and next-session return forecast with global/event filters.

Swing: multi-day return/range ranking and volatility sizing.

Options: delta-controlled directional structures, defined-risk spreads, volatility trades comparing forecast range with implied risk, and selected relative-value structures.

All are research families, not approved strategies. Underlying forecast skill must be revalidated at the actual traded-instrument P&L level.
