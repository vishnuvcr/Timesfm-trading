# Cost model

All backtests report gross and net performance.

Net cost components: brokerage, exchange charges, statutory charges, taxes, spread, slippage, impact, financing and instrument-specific settlement costs.

Paytm Money assumptions are stored by effective date because current official pages and historical account cohorts differ. See the research log before freezing any rate table.

Options must be modeled at contract level; underlying slippage is not used as an option execution proxy.
